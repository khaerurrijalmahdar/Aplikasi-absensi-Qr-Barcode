# Aplikasi Absensi QR Code

Aplikasi absensi berbasis web dengan fitur scan QR Code yang cepat dan dilengkapi animasi keren. Cocok untuk sekolah, kantor, atau event yang membutuhkan sistem absensi digital.

![Demo](assets/images/demo.gif) *(opsional: tambahkan screenshot atau GIF demo)*

## ✨ Fitur

- Scan QR Code langsung dari browser
- Animasi scanning yang smooth dan modern
- Responsif di desktop dan mobile
- Mudah dikembangkan dan di-deploy
- Open source dan gratis
